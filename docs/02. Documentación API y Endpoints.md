# 📘 Project Planner API — Catálogo de Endpoints

> **Versión:** 1.0.0  
> **Especificación:** OpenAPI 3.0.3 (Generada automáticamente con `drf-spectacular`)  
> **Acceso interactivo en navegador:** `http://127.0.0.1:8000/api/docs/` (Swagger UI) y `http://127.0.0.1:8000/api/redoc/` (Redoc)  

Este documento reúne y cataloga todos los endpoints disponibles en el backend Django REST Framework de Project Planner, listo para consulta y uso en **Obsidian** o exportación a **PDF**.

## 1. 🔐 Autenticación y Usuarios

| Método | Endpoint | Acción / Descripción |
| :--- | :--- | :--- |
| `POST` | `/api/auth/login/` | Endpoint de autenticación para verificar credenciales de usuario y rol. |
| `POST` | `/api/auth/logout/` | Registra el cierre de sesión del usuario para marcarlo desconectado en la Base de Datos. |
| `GET` | `/api/auth/users-status/` | Retorna la lista de usuarios técnicos con su estado real de conexión (isOnline) |
| `PATCH` | `/api/auth/users-status/` | Retorna la lista de usuarios técnicos con su estado real de conexión (isOnline) |
