# 📊 Flujo de Negocio y Procesos — Project Planner

Este documento modela visualmente los procesos de negocio corporativos, la arquitectura de integración y el ciclo de vida del sistema **Project Planner** mediante diagramas estándar **Mermaid** estructurados para encajar perfectamente en exportación a **PDF (A4)**.

---

## 1. 🏢 Flujo de Negocio: Planificación y Aprobación (Fases 1 y 2)

Representa el ciclo desde la formulación inicial de la propuesta hasta la asignación de recursos y especialistas.

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '12px'}, 'flowchart': {'nodeSpacing': 20, 'rankSpacing': 30}}}%%
flowchart TD
    Start([🚀 Inicio: Solicitud de Proyecto]) --> Reg[1. Registro de Proyecto<br/>en Plataforma]
    Reg --> EvalPresupuesto{¿Presupuesto<br/>> $100,000?}
    
    EvalPresupuesto -- Sí --> RevDirectiva[Revisión por Comité Directivo]
    EvalPresupuesto -- No --> AprobLider[Aprobación Directa Líder Técnico]
    
    RevDirectiva --> Dictamen{¿Aprobado?}
    Dictamen -- No --> Rechazado([❌ Proyecto Rechazado / Archivado])
    Dictamen -- Sí --> ConfigPlan[2. Definir Hitos Globales<br/>y Calendario Maestro]
    AprobLider --> ConfigPlan
    
    ConfigPlan --> SelArea[3. Seleccionar Área Técnica:<br/>Civil, Arquitectura, Estructuras, Sistemas]
    SelArea --> AsigEquipo[4. Asignar Especialistas y Líder]
    AsigEquipo --> FinFase([➡️ Pasar a Fase Operativa])

    classDef inicio fill:#0284c7,stroke:#0369a1,color:#fff;
    classDef fin fill:#059669,stroke:#047857,color:#fff;
    classDef alerta fill:#dc2626,stroke:#b91c1c,color:#fff;
    classDef decision fill:#d97706,stroke:#b45309,color:#fff;
    classDef paso fill:#1e293b,stroke:#475569,color:#f8fafc;

    class Start inicio;
    class FinFase fin;
    class Rechazado alerta;
    class EvalPresupuesto,Dictamen decision;
    class Reg,RevDirectiva,AprobLider,ConfigPlan,SelArea,AsigEquipo paso;
```

## 2. 🔨 Flujo de Negocio: Ejecución y Cierre (Fases 3 y 4)

Control de tareas en campo, verificación de ruta crítica, auditoría y cierre contable.

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '12px'}, 'flowchart': {'nodeSpacing': 20, 'rankSpacing': 30}}}%%
flowchart TD
    StartOp([▶️ Inicio Fase Operativa]) --> Desglose[1. Desglose en Órdenes de Trabajo]
    Desglose --> RutaCritica[2. Identificar Ruta Crítica y Holgura 7d]
    RutaCritica --> Ejecucion[3. Ejecución de Tareas por Especialistas]
    Ejecucion --> PlanosBIM[4. Vincular Planos Drive y Modelos 3D APS]
    PlanosBIM --> ControlAvance[5. Monitoreo de Avance y Costos]
    
    ControlAvance --> CheckRiesgo{¿Riesgo de<br/>Atraso > 7d?}
    CheckRiesgo -- Sí --> Opt[Algoritmo de Optimización<br/>/ Fast-Tracking]
    Opt --> Ejecucion
    CheckRiesgo -- No --> CheckHitos{¿Hito Crítico<br/>Cumplido?}
    
    CheckHitos -- No --> Ejecucion
    CheckHitos -- Sí --> AprobHito[Aprobación por Supervisor]
    
    AprobHito --> CheckFin{¿100% de Tareas<br/>Completadas?}
    CheckFin -- No --> Ejecucion
    CheckFin -- Sí --> Liquidacion[6. Liquidación y Auditoría Final]
    Liquidacion --> Webhook[7. Disparo Webhook a Make<br/>Alerta Discord y Gmail]
    Webhook --> FinTotal([🏁 Proyecto Concluido con Éxito])

    classDef inicio fill:#0284c7,stroke:#0369a1,color:#fff;
    classDef fin fill:#059669,stroke:#047857,color:#fff;
    classDef decision fill:#d97706,stroke:#b45309,color:#fff;
    classDef paso fill:#1e293b,stroke:#475569,color:#f8fafc;

    class StartOp inicio;
    class FinTotal fin;
    class CheckRiesgo,CheckHitos,CheckFin decision;
    class Desglose,RutaCritica,Ejecucion,PlanosBIM,ControlAvance,Opt,AprobHito,Liquidacion,Webhook paso;
```

## 3. ⚡ Secuencia 1: Creación de Proyectos y Notificaciones Make

```mermaid
%%{init: {'sequence': {'useMaxWidth': true, 'mirrorActors': false, 'actorFontSize': 11, 'messageFontSize': 10, 'boxMargin': 4, 'noteMargin': 4}}}%%
sequenceDiagram
    autonumber
    actor U as 👤 Líder
    participant F as 💻 Frontend
    participant B as ⚙️ Django API
    participant M as 🟣 Make

    U->>F: Login con credenciales
    F->>B: POST /api/auth/login/
    B-->>F: 200 OK (Sesión y Rol)
    F-->>U: Muestra Dashboard

    U->>F: Crear proyecto y presupuesto
    F->>B: POST /api/projects/
    B->>B: Guarda en PostgreSQL
    B->>M: Webhook (project.created)
    M-->>U: Alerta a Discord y Gmail
    B-->>F: 201 Created
    F-->>U: Confirmación visual en UI
```

## 5. 🔄 Ciclo de Vida del Proyecto (Estados)

```mermaid
stateDiagram-v2
    [*] --> PLANNING : Alta de proyecto
    
    PLANNING --> IN_PROGRESS : Aprobación formal
    PLANNING --> CANCELLED : Desestimado
    
    state IN_PROGRESS {
        [*] --> EnPlazo
        EnPlazo --> EnRiesgo : Retraso crítico (>7d)
        EnRiesgo --> EnPlazo : Optimización aplicada
    }

    IN_PROGRESS --> STAND_BY : Pausa operativa
    STAND_BY --> IN_PROGRESS : Reanudación
    
    IN_PROGRESS --> COMPLETED : 100% completado
    STAND_BY --> CANCELLED : Cancelación
    
    COMPLETED --> [*] : Cierre contable
    CANCELLED --> [*] : Archivado
```

## 6. 🧮 Algoritmo de Optimización de Cronograma (Ruta Crítica)

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '12px'}}}%%
flowchart TD
    A[Inicio: Análisis de Cronograma] --> B[Identificar Tareas de Ruta Crítica]
    B --> C{¿Holgura Total == 0?}
    C -- No --> D[Tarea con holgura: No afecta fecha final]
    C -- Sí --> E[Evaluar tolerancia de 7 días]
    E --> F[Reasignar especialistas técnicos]
    F --> G[Compresión de calendario / Fast-Tracking]
    G --> H[Generar cronograma sugerido]
    D --> H
    H --> I([Fin: Presentación al Líder])

    classDef proc fill:#1e293b,stroke:#475569,color:#f8fafc;
    classDef dec fill:#d97706,stroke:#b45309,color:#fff;
    classDef term fill:#0284c7,stroke:#0369a1,color:#fff;

    class A,I term;
    class C dec;
    class B,D,E,F,G,H proc;
```
